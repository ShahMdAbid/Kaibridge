# abIDE 

**abIDE** is a next-generation KiCad plugin designed to empower Autonomous AI Agents (like LLMs) to design, place, and route Printed Circuit Boards (PCBs) entirely on their own. It bridges the gap between text-based AI models and the  world of complex, visually-driven electronic design automation (EDA).

Designs with a `sheets` block compile to a hierarchical schematic — a root sheet plus one file per sub-sheet. Designs without one compile to a single sheet, exactly as before.
